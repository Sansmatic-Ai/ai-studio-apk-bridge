# Contributing

Thanks for your interest! Bug reports, browser compatibility reports and pull
requests are welcome.

1. Open an issue first for anything larger than a small fix.
2. Fork the repo, create a branch, make your change in `extension/`.
3. Test by loading the `extension/` folder unpacked in a Chromium browser
   (see `docs/ANDROID-BROWSERS.md`).
4. Open a pull request describing what changed and which browser/version you
   tested on.

original work; contributors are credited through Git history and releases.
