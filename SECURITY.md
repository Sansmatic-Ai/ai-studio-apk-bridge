# Security Policy

## Reporting a vulnerability

Please do **not** open a public issue for security problems.
Use GitHub's private reporting: **Security tab -> Report a vulnerability**.
You can expect a first reply within about 7 days.

## Supported versions

Only the latest release receives fixes.

## Safe use

Only install APKs you built yourself from your own AI Studio project, and
review what you are installing before you tap Install on your device.
